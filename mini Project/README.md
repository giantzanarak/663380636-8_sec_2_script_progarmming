## 1. ภาพรวมโปรเจค

ระบบยืม-คืนหนังสือแบบ Command-line ที่เขียนด้วยภาษา Python (Jupyter Notebook) จำลองการทำงานของห้องสมุดขนาดเล็ก รองรับการจัดการหนังสือ สมาชิก การยืม-คืน การคิดค่าปรับเมื่อคืนเกินกำหนด และบันทึกข้อมูลลงไฟล์ JSON เพื่อให้ข้อมูลไม่หายเมื่อปิดโปรแกรม

## 2. ฟีเจอร์หลัก (เมนู)

| เมนู | ฟังก์ชัน | หน้าที่ |
|---|---|---|
| 1 | เพิ่มหนังสือ | สร้าง ISBN อัตโนมัติ (ISBN001, ISBN002, ...) |
| 2 | แสดงหนังสือทั้งหมด | แสดงรายการพร้อมจำนวนที่ว่าง |
| 3 | ค้นหาหนังสือ | ค้นด้วยคำสำคัญจากชื่อ/ผู้แต่ง |
| 4 | ลงทะเบียนสมาชิก | สร้างรหัสสมาชิกอัตโนมัติ (M001, M002, ...) |
| 5 | แสดงสมาชิก | แสดงสมาชิกพร้อมจำนวนเล่มที่ยืมอยู่ |
| 6 | ยืมหนังสือ | ตรวจสอบ 4 ขั้นก่อนยืม, กำหนดคืน 14 วัน |
| 7 | คืนหนังสือ | คำนวณค่าปรับ 5 บาท/วัน หากเกินกำหนด |
| 8 | รายการยืมของฉัน | แสดงหนังสือที่ยืมอยู่และสถานะเกินกำหนด |

| 0 | ออกจากระบบ | บันทึกข้อมูลลง `library_data.json` ก่อนออก |

## 3. โครงสร้างข้อมูล

- `books` (dict) — key คือ ISBN, value คือ `title`, `author`, `total`, `available`
- `members` (dict) — key คือ member_id, value คือ `name`, `email`, `borrowed_books`, `joined_date`
- `borrow_log` (list) — ประวัติการยืมแบบ append-only แต่ละรายการมี `log_id`, `isbn`, `member_id`, `borrow_date`, `due_date`, `returned_date`
- ตัวนับ `_log_id`, `_book_id`, `_member_id` สำหรับสร้าง ID อัตโนมัติ

## 4. แนวคิดสำคัญที่ใช้

1. **เลือกใช้ dict** — ค้นหาด้วย ISBN/รหัสสมาชิกได้ทันที O(1) แทนการวนหาใน list O(n)
2. **Append-only Log** — การคืนหนังสือคือการอัปเดต `returned_date` ไม่ลบรายการ ทำให้ประวัติตรวจสอบย้อนหลังได้
3. **Validate Before Mutate** — `borrow_book()` ตรวจครบ 4 เงื่อนไข (มีหนังสือ / หนังสือว่าง / มีสมาชิก / ไม่ยืมซ้ำ) ก่อนแก้ข้อมูล
4. **`next()` + Generator Expression** — หา log ที่ยังไม่คืนรายการแรกใน `return_book()`
5. **แยก UI ออกจาก Core** — ฟังก์ชัน `_ui_*()` รับ input แล้วส่งต่อให้ core ทำให้ทดสอบ core ได้ง่าย
6. **Dispatcher Dict** — `main_menu()` จับคู่ตัวเลือกเมนูกับฟังก์ชัน
7. **Data Persistence** — `json.dump()` / `json.load()` พร้อมตรวจ `os.path.exists()` ก่อนโหลด
8. **Error Handling** — `try` / `except` / `raise` กับ `KeyError` และ `ValueError`
9. **อื่น ๆ** — f-string + format spec (`:<N>`, `:03d`), `lambda` + `sorted()`, `dict.get()`, type hints และ docstring

## 6. การทดสอบ

ทดสอบทั้งหมด 8 กลุ่ม — **ผ่านทุกกรณี ✅**

| กลุ่ม | สิ่งที่ทดสอบ |
|---|---|
| T1 | เพิ่ม/ค้นหาหนังสือ, จำนวน 0 ต้อง error |
